# MODLER v2 简易使用教程

MODLER v2 是 ALGAVISION 中的**模型训练与主动学习**工具，用于浮游生物图像分类：从少量标注或零标注起步，通过聚类冷启动、批量预测与人工审核，以较少人工代价持续改进模型。

---

## 1. 启动

**方式一（推荐）** — 双击项目根目录下的 `MODLER.bat`

**方式二** — 命令行：

```bash
cd ALGAVISION
python run_modler.py
```

启动后界面顶部显示 GPU/CPU 信息；右侧为图像预览、预测结果与操作日志。

> **环境要求**：已安装 `requirements.txt` 中的依赖；建议使用 NVIDIA GPU。流程图见 `resources/diagrams/active_learning_unsupervised_flow.drawio`。

---

## 2. 界面结构

主界面分为 **5 个标签页**，按顺序完成工作：

| 标签 | 作用 |
|------|------|
| ① 数据准备 | 配置训练、归档、审核等目录 |
| ② 自动标注 | 无监督聚类标注；配置主动学习策略 |
| ③ 模型训练 | 选择骨干网络、超参数，训练或微调 |
| ④ 批量预测 | 对无标签文件夹推理，自动分流 |
| ⑤ 人工审核 | 处理低置信 / OOD 样本 |

右侧固定面板：**图像预览**、**预测结果表**、**操作日志**。

---

## 3. 数据目录说明

在 **① 数据准备** 中配置以下路径（首次使用可保留默认）：

| 目录 | 默认路径 | 说明 |
|------|----------|------|
| 训练数据集 | `./class/training_data` | 按类别分子文件夹，见下方结构 |
| 归档目录 | `./class/archived_data` | 伪标签与人工确认样本的存放处 |
| 待审核队列 | `./class/review_queue` | 需人工确认的图像 |
| 风格来源（可选） | 未设置 | 选「风格迁移」增强时，放 FlowCAM/显微镜样本 |

**训练数据目录结构**（每个类别一个子文件夹）：

```
training_data/
├── 硅藻/
│   ├── img001.jpg
│   └── img002.jpg
├── 甲藻/
│   └── ...
└── 桡足类/
    └── ...
```

右侧 **数据集概览** 会实时显示总样本数、已确认、伪标签、待审核与类别数。

## 4. 推荐工作流

### 场景 A：从零开始（无标签目标域图像）

```
② 无监督标注 → ① 设为训练目录 → ③ 训练 → ④ 批量预测 → ⑤ 审核 → ③ 微调 → 循环
```

1. **② 自动标注** → 点击「启动无监督标注工具」
   - 选择无标签图像文件夹（FlowCAM / 显微镜 ROI）
   - 运行聚类（默认 DINOv2 + HDBSCAN）
   - 为每个簇命名（杂质簇可跳过）；导出到 `unsup_labeled/`
   - 提示时选择「设为训练数据目录」

2. **③ 模型训练**
   - 骨干网络建议新手选 `B2` 或 `B0`
   - 增强选「显微镜增强」；有标准照 + 域偏移大可试「风格迁移」
   - 点击「开始训练」，等待曲线与日志完成

3. **④ 批量预测**
   - 选择待预测文件夹
   - 高置信（默认 ≥0.90）→ 伪标签归档；中等置信 → 审核队列；过低 → 丢弃
   - 可在 **②** 中调整采样策略（默认 `entropy`）与 OOD 检测

4. **⑤ 人工审核**
   - 逐张确认或修正类别 →「确认归档」
   - 可「新建类别」处理未见过的类

5. 返回 **③** →「微调模型」，进入下一轮迭代

---

### 场景 B：已有标注数据

```
① 指定训练目录 → ③ 训练 → ④ 批量预测 → ⑤ 审核 → ③ 微调
```

跳过 **②**，直接在 **①** 指向已有 `class_name/*.jpg` 结构的数据集即可。

## 5. 各标签页操作要点

### ① 数据准备

- 点击各目录旁的「浏览…」选择路径
- 确认右侧统计卡片数字合理后再进入训练
- 「风格来源目录」仅在增强级别为「风格迁移」时需要

### ② 自动标注

**左侧 — 无监督聚类**

- 适合大量无标签 ROI 的冷启动
- 噪声簇（label = -1）对应碎屑/杂质，命名时可跳过
- 导出结果可直接作为训练目录

**右侧 — 主动学习策略**（影响 **④ 批量预测** 时的分流逻辑）

| 策略 | 说明 |
|------|------|
| entropy | 信息熵，综合不确定度，**推荐默认** |
| margin | top-2 概率差越小越优先送审 |
| least_confidence | 最大概率越低越优先送审 |
| coreset | 嵌入空间多样性采样 |
| max_softmax | 基础基线 |

勾选 **OOD 检测** 后，碎屑/气泡/域外生物强制进入审核队列，不写入伪标签。

### ③ 模型训练

| 参数 | 建议 |
|------|------|
| 骨干网络 | 生产环境 `B2`；资源少用 `B0`；精度优先可试 ConvNeXtV2 / DINOv2 |
| Epochs | 初次 20；微调 5–10 |
| 学习率 | 默认 `1e-3`；微调可降至 `1e-4` |
| 批次 | 32；显存不足勾选「自动」 |
| 增强 | 显微镜图像用「显微镜增强」 |
| 早停 | 默认 5，验证集无提升则停止 |

按钮说明：

- **开始训练** — 从头训练（需已配置训练目录且含 ≥2 类）
- **微调模型** — 在已有 checkpoint 上继续训练（审核归档后常用）
- **加载 / 保存模型** — 手动管理权重文件
- **超参数自动调优** — 自动搜索较优超参（耗时较长）

训练日志与曲线显示在标签页右侧；checkpoint 默认保存在 `./runs/` 下。

### ④ 批量预测

| 阈值 | 默认 | 含义 |
|------|------|------|
| 自动归档阈值 | 0.90 | 置信度 ≥ 此值 → 伪标签归档 |
| 审核阈值 | 0.50 | 介于两阈值之间 → 送审核；低于审核阈值 → 丢弃 |

操作：

- **选择单张图像预测** — 快速测试当前模型
- **批量预测文件夹** — 对整文件夹推理并自动分流
- **导出 Excel 报告** — 汇总预测与审核记录

本轮统计卡片显示：已处理 / 伪标注归档 / 送审核 / 已丢弃。

### ⑤ 人工审核

| 操作 | 说明 |
|------|------|
| ◀ / ▶ | 切换待审核图像 |
| 修正类别 + 确认归档 | 写入归档目录，计入已确认样本 |
| 新建类别并归档 | 发现新类时使用 |
| 删除此图像 | 从队列移除，不归档 |

**快捷键**：`←` `→` 切换；`Enter` 确认归档；`Del` 删除。

审核完成后 → **③ 微调模型** → 再次 **④ 批量预测**，形成自学习闭环。

## 6. 一轮完整迭代（速查）

```
1. ① 检查目录与统计
2. ③ 训练 或 微调
3. ④ 批量预测新样本
4. ⑤ 审核不确定样本
5. ③ 微调 → 回到步骤 3
```

**一句话概括**：用聚类或已有标注训练分类器，让模型自动归档高置信样本，只把不确定的送给人工，再微调模型反复迭代。

## 7. 输出与下游使用

| 输出 | 位置 | 用途 |
|------|------|------|
| 训练 checkpoint | `./runs/run_*/` | 继续微调或加载预测 |
| 伪标签 / 确认样本 | 归档目录 `类别名/*.jpg` | 下一轮训练数据 |
| 审核队列 JSON | `review_queue/*.json` | 记录预测概率，供审核参考 |
| Excel 报告 | 用户指定路径 | 预测与审核汇总 |
| 部署模型 | `Models/`（手动复制） | 供 **SORTA** 识别调用 |

将训练好的权重与 `classes_names.txt` 放入 `Models/` 对应子目录后，可用 `run_sorta.py` 做野外样本识别与计数。

## 8. 常见问题

**Q：训练按钮灰色或提示未选目录？**  
先在 **①** 选择训练数据集目录，并确保至少 2 个类别、每类有若干张图。

**Q：无监督标注找不到模块？**  
确认 `src/cluster_review_gui.py` 存在，且通过 `MODLER.bat` 或 `run_modler.py` 启动（已设置 `PYTHONPATH`）。

**Q：GPU 未被使用？**  
查看顶部设备栏；若显示 CPU，请检查 PyTorch CUDA 安装是否与显卡驱动匹配。

**Q：伪标签太多、错误率高？**  
在 **④** 提高自动归档阈值（如 0.95）；在 **②** 开启 OOD 检测。

**Q：审核队列积压？**  
优先处理 **⑤**；调高归档阈值减少进入队列的样本；或先用更小批量预测试水。

**Q：类别不平衡？**  
尝试 ConvNeXtV2 / DINOv2；增强级别选「显微镜增强」或「风格迁移」；多轮微调补充少数类样本。
